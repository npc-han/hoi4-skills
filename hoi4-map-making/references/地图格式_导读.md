## 关键知识速查（map/ 目录完整格式）

- **省份**：`definition.csv`（RGB→省份 ID 映射）+ `provinces.bmp`（24-bit，不带色彩空间信息）
- **战略区**：`map/strategicregions/*.txt`（`id`/`name`/`provinces`/`weather`，id 必须连续否则崩溃）
- **邻接**：`adjacencies.csv` + 邻接规则（type/through/comment/start_x 等）
- **地形**：terrain 位图 + 省级/图形地形定义（0-31 索引）+ atlas 图集 + 海军地形
- **高度/法线**：`heightmap.bmp` + 法线贴图（4 种生成工具）
- **河流**：`rivers.bmp` 颜色索引表（绿=源头、红=汇流、蓝渐变=宽度）
- **建筑/单位/胜利点**：`buildings.txt`、`unitstacks`（0-38）、`victory_points`（州级）
- **补给**：见本目录 `补给与铁路教程（wiki译文）.md`
- **环境**：`ambient_objects`、`weatherpositions.txt`
- **⚠️ 常见地图错误清单**：`MAP_ERROR` 7 类（省份无大洲、TOO LARGE BOX、像素越界、CRLF 换行问题等）

## 怎么用

- **改地图**：先读 `地图制作完整教程（wiki译文）.md` 对应章节确定格式 → 用 Nudge（`Nudge地图工具教程（wiki译文）.md`）或 B站 P2/P4/P5/P6 实操 → 按 7 类 MAP_ERROR 清单自查
- **空军机制**（空战区 = 战略区，空军基地 = 州级建筑）：读 `战略区教程（wiki译文）.md` + `省份State教程（wiki译文）.md` 的 air_base 部分
- **排查崩溃**：地图相关崩溃按"加载时崩溃"排查（BMP 格式/维度、无效省份 ID、id 不连续），配合 `01-入门与语法/报错与排查.md`
