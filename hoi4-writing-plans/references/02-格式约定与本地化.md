# 02-格式约定与本地化(Formats & Localisation)

HOI4 文件级硬格式规则与本地化语法——"不报错但不生效"问题的根源大多在这里。


> ⚠️ 本文件所有规则都有一个共同特征:**违反它们往往不报错,只表现为"功能不生效"或"显示异常"**。排查时优先怀疑本文件内容。

---

## 1. 本地化文件基础(Localisation Files)

- 位置:`mod/localisation/*_l_english.yml`(文件名必须以 `_l_english.yml` 结尾;简体中文用 `_l_simp_chinese.yml`)。
- 首行声明语言:`l_english:` / `l_simp_chinese:`。
- 每条条目:`key: "文本"`(进阶格式可带版本号 `key:0 "文本"`)。

代码示例:
```
l_english:
 my_mod_focus_1: "进军柏林"
 my_mod_focus_1_desc: "我们必须在圣诞节前抵达柏林。"
 my_mod_event.1.t: "重大消息"
```

> 提醒:本地化文件必须为 **UTF-8 带 BOM(utf8-bom)** 编码。否则游戏输出警告(见下)并可能整文件不加载,所有文本显示为原始 key(如 `my_mod.1.t`)。

错误消息对照:
```
[14:25:00] File 'mod/xxx_l_english.yml' should be in utf8-bom encoding (will try to use it anyways), near line: 1
```
修复:编辑器里"另存为 → UTF-8 with BOM"(Notepad++/VS Code 均可)。

> ⚠️ 重要区分:本归档文件自身用 UTF-8 **无** BOM(方便 AI 读取);但**写进 mod 的 .yml 文件必须带 BOM**。两者不是一回事。

## 2. 覆盖原版字符串(Overriding Vanilla Loc)

- 要覆盖原版文本(如修改原版国策名),把 yml 放进 `localisation/replace/` 子文件夹——**文件夹名必须恰好是 `replace`**,其他名字一律不识别。
- 不覆盖时,你的 key 与游戏原版 key 冲突会报 `loc key collisions`(见 03)。

## 3. 特殊字符与格式化(Special Characters)

| 语法 | 作用 | 示例 |
|---|---|---|
| `\n` | 换行 | `"第一行\n第二行"` |
| `§R` `§G` `§B` `§Y` `§W` `§C` `§O` | 颜色(红/绿/蓝/黄/白/青/橙),`§!` 结束 | `"§R警告§! 内容"` |
| `£icon£` | 文本图标(图标在 .gfx 定义,如 texticons.gfx) | `"£army_experience£ +50"` |
| `$key$` | 嵌套另一个本地化键 | `"完成 $my_mod_focus_1$ 后启用"` |
| `$$` | 显示字面 `$` | `"价格:$$5"` |
| `[?var\|%G0]` | 变量格式化(见下) | `[?party_popularity@democracy\|%G0]` |

**变量格式化 `[?var|格式]`** 的格式符:
- `%` → 显示为百分比;`*` → SI 单位;`=` → 自动加 `+`/`-` 前缀;`0`-`9` → 小数位数。
- 例:`[?my_mod_var|%G1]` = 以百分比显示、绿色(`G`)、1 位小数。

> 提醒:颜色代码段以 `§!` 结束,否则后续文本全被染色。中文文本中这些符号不是全角,必须是半角。

## 4. .mod 描述文件(Descriptor)

一个 mod 有两个描述文件,职责不同:

| 文件 | 位置 | 必含字段 |
|---|---|---|
| `<mod名>.mod` | 游戏 mod 根目录(`Documents/Paradox Interactive/Hearts of Iron IV/mod/`) | `name`、`path`、`tags`、`supported_version` |
| `descriptor.mod` | mod 文件夹内部 | 同上但**不应含 `path` 行** |

```
name = "My Mod"
path = "mod/My_Mod"          # 根目录 .mod 需要;descriptor.mod 不要写
tags = { "National Focuses" "Events" }
supported_version = "1.17.*"  # 两个点;版本号格式错误会报 Invalid supported_version
```

> 提醒:`supported_version` 格式是 `"1.17.*"` 或 `"1.17.3"`(**两个点**),写三个点(如 `"1.17.3.5"`)会报错。`path` 建议只用罗马字母/数字。launcher 与游戏读到的 mod 名不一致(descriptor 与 .mod 的 name 不同)会静默失效。

## 5. Defines 覆盖(Defines Override)

- 原版数值定义在 `common/defines/00_defines.lua`:顶层表 `NDefines`,下含 `NGame`/`NMilitary`/`NCountry`/`NInterface`/`NFrontend` 等子表(引用如 `NGame.END_DATE`)。
- **覆盖规则:在 mod 的 `common/defines/` 放一个新文件**(如 `01_defines.lua`),文件名 Unicode 序号晚于 00 即可(几乎任何非 0 开头字母都行)。
- **绝不要复制整个 `00_defines.lua` 进 mod**:小版本更新会改它,你复制的旧版缺任何一行都会导致 mod 不稳定甚至**启动崩溃**。

代码示例(`mod/common/defines/01_defines.lua`):
```
NDefines.NGame.END_DATE = "2034.1.1.1"    # 修改结束日期,只写要改的!
```
> 提醒:`common/defines/*.lua` 是 Lua 文件,注释用 `--`,不是 `#`。

## 6. 属性可重复与任意属性名(Duplicated Attributes)

- 同一属性可合法重复出现:多个 `focus = { }` 块 = 创建多个国策;多个 effect 块 = 按顺序执行。
- 有些属性名是**任意的**(无固定名称):如国家精神(idea)的块名就是它的 ID(`my_mod_spirit = { ... }` 中 `my_mod_spirit` 既是块名也是引用名)。
- 反之,effect/trigger 关键字是**固定的**:拼错 = 报 Unknown effect/trigger(见 03)。

## 7. 编码与扩展名陷阱(Encoding & Filename Traps)

| 症状 | 根因 | 修复 |
|---|---|---|
| 中文乱码 | 文件不是 UTF-8 或首行语言键与文件名不符 | 统一 UTF-8 with BOM;`l_simp_chinese:` 配 `_l_simp_chinese.yml` |
| 本地化整文件不加载 | ① 无 BOM ② 首行错 ③ 文件名不以 `_l_english.yml` 结尾 ④ **实际扩展名是 `.yml.txt`**(Windows 隐藏了扩展名) | 逐项检查;在资源管理器"查看"里勾选"文件扩展名" |
| txt 代码文件不加载 | 非 UTF-8 编码,游戏静默跳过整个文件 | 统一 UTF-8(不带 BOM 即可,游戏宽容) |
