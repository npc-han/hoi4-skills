# 03-报错与排查(Troubleshooting & Errors)

中英对照错误消息字典 + 系统化崩溃定位流程(网络资料增量部分)。


> 🔗 **重要**:本文件为报错排查参考,实际排查以游戏 error.log 与日志表现为准。d`(三种失败模式、12 类分类表、静默失败清单、排查决策树,均已验证)。**排查先读那份,再用本文件查错误原文和崩溃定位细节**。

---

## 1. 日志位置与启动选项(Logs & Launch Options)

| 项 | 位置/说明 |
|---|---|
| error.log | `Documents/Paradox Interactive/Hearts of Iron IV/error.log` |
| 崩溃信息 | 同目录 `crashes/` 文件夹 |
| 本地化冲突 | `logs/text.log` |
| 控制台文档 | `logs/game.log`(`trigger_docs` 命令写入) |
| `-debug` | 启动参数,error.log 才记录完整报错(开发期间必须用) |
| `-crash_data_log` | 启动参数,让 `crashes/` 里的 `meta.yml` 记录崩溃前**最后读取的代码行**:`LastRead: map/supply_nodes.txt (727)`(727 = 行号)。**显著拖慢游戏,仅崩溃调试用** |

> 提醒:`LastRead` 指向的是崩溃时正在读的文件。但**空文件会被游戏跳过**,所以同样的问题在日志里可能显示为不同的文件——文件为空时先怀疑"内容根本没被读"。

## 2. 错误消息对照字典(中英对照)

格式: 错误原文 → 中文解释 → 原因 → 修复。按类别组织(分类体系与 `常见报错解读.md` 的 12 类互相兼容)。

### 2.1 版本号 / 描述符类(Descriptor & Version)

| 错误原文 | 解释 / 原因 / 修复 |
|---|---|
| `Invalid supported_version in file: mod/xxx.mod line: 10` | supported_version 格式错(如点号太多)。用 `"1.17.*"` 或 `"1.17.3"`——**两个点** |
| `Incorrect MOD descriptor: "mod/xxx.mod"` | .mod 文件畸形。根目录 .mod 应含 `path=`;文件夹内 descriptor.mod **不应含** `path` |
| `duplicate script enum definition: ... at common/script_enums.txt:686` | script_enums 重复定义(待核验:本地库未找到原文,标注来源=wiki 搜索摘要) |

### 2.2 国家 tag 类

| 错误原文 | 解释 / 原因 / 修复 |
|---|---|
| `SOV - is not in the tag list` | 引用了不存在的国家 tag。检查 tag 拼写(大写)与是否已定义 |

### 2.3 本地化类

| 错误原文 | 解释 / 原因 / 修复 |
|---|---|
| `The game has loc key collisions. Check logs/text.log for more details` | 本地化键冲突(两个文件定义同一 key)。查 text.log;覆盖原版键用 `localisation/replace/`(见 02) |
| 国策/事件名显示为 "undefined" | 缺本地化条目或 yml 未加载(编码/BOM/文件名问题,见 02) |

### 2.4 GFX / 纹理类

| 错误原文 | 解释 / 原因 / 修复 |
|---|---|
| `Icon definition "" does neither look like a file path nor a GFX entry as it does not start with "GFX_"` | 图标引用无效:既不是文件路径也不是以 `GFX_` 开头的 sprite 条目 |
| `Texture ... .dds have forbidden compression, have you tried DXT3?` | .dds 压缩格式不允许。用 DXT3(或其他游戏支持格式)重新导出 |
| `Failed to create gui object. Could not find sprite type [GFX_...]` | 引用的 spriteType 未注册。在 `interface/*.gfx` 注册同名条目,名字**大小写敏感** |
| `Texture Handler encountered missing texture file: ...` / `Couldn't find texture file: ...` | 贴图文件缺失/路径错。检查路径(正斜杠 `/`)与文件名 |
| `Could not find music named ...` | 音乐引用缺失 |

### 2.5 trigger / effect 类

| 错误原文 | 解释 / 原因 / 修复 |
|---|---|
| `Invalid trigger 'XXX' in common/ideas/xx.txt line : 7` / `Unknown trigger-type: XXX, near line: 7` | trigger 名拼写错误或不存在。查本地 triggers_documentation.md |
| `Invalid effect 'XXX' in ... line : 327` / `Unknown effect-type: XXX, near line: 327` | effect 名拼写错误,或**把 trigger 写在了 effect 位置**。查本地 effects_documentation.md |
| `Non assign effect is not enclosed in {}: set_capital, near line: ...` | 需要块参数的 effect 没写花括号 |
| `Unexpected token` | 结构性错误(括号不闭合、引号未闭合等)。**报错行号可能误导**——实际错误在别处(如用户报告:重试后行号每次上移一行,真正原因是不闭合的括号) |
| `has_completed_focus = XXX` 校验失败 | 引用的国策 ID 不存在。注意:**国策效果执行期间该国策尚未标记完成**,其内部 `has_completed_focus` 恒为 false |

### 2.6 州 / 地图类

| 错误原文 | 解释 / 原因 / 修复 |
|---|---|
| `State #743 does not have a category defined` / `State #743 has no people living in it` | 新州缺 `state_category = ...` 和 `manpower = ...`(参考原版州文件格式) |
| `map/buildings.txt error: map building(Military Factory) location is not within specified state` | 建筑指向了错误州。用 Nudge 重算/重分配建筑 |
| `Attempting to set capital state #563 for X, they don't own it!` | 首都设在了国家不拥有的州 |
| `Map invalid X crossing. Please fix pixels at coords` | 四个省共享一个角点(游戏会错误连接对角省)。地图是横向循环的,边界处也会出现 |
| `Province X has TOO LARGE BOX. Perhaps pixels are spread around the world in provinces.bmp` | 省宽/高超过地图 1/8。通常是两个省意外共色,或省真的过大(游戏不支持) |
| `Province X has only N pixels` | 省像素低于 `NGraphics.MINIMUM_PROVINCE_SIZE_IN_PIXELS`,过小不可用 |
| `Bitmap and province definition disagree on whether or not province X is coastal` | provinces.bmp 与 definition.csv 对沿海与否判断不一致,或 **definition.csv 缺行导致后续颜色-ID 映射全部错位**(地形模式破碎也是此症状) |
| `One-pixel province color found` | 无害警告,可用脚本清理(如 HOI4-mod-tools 的 remove_one_pixel_province.py) |
| `Province has no pixels in provinces` | 编辑后省无像素,需手动修正 |

## 3. 崩溃定位:LastRead 对照表

`-crash_data_log` 记录的崩溃前最后读取文件 → 常见根因(**待核验**: 下表来自 wiki 搜索摘要,建议实际遇到时验证):

| LastRead 文件 | 常见根因 |
|---|---|
| `common/countries/cosmetic.txt` | 完全覆盖了 `common/national_focus/` 或 `common/continuous_focus/`(数据库缺条目) |
| `map/rocketsites.txt` | 完全覆盖了 `history/states/` 或 `common/unit_leader/`(states 没有 generic 文件,必须手写) |
| `common/national_focus/*.txt` | `shared_focus = my_focus` 引用不存在的国策 |
| `gfx/models/supply/railroad.shader` | provinces.bmp 错误:尺寸不是 256 倍数、文件超 40 MiB、各 bmp 间尺寸不一致(除 trees.bmp)、DIB 头格式错(用 BITMAPINFOHEADER 而非 BITMAPV5HEADER) |
| `history/general/*.txt` 等 | replace_path 删掉了原版必需文件(见下) |

## 4. replace_path 陷阱

- **两个 .mod 文件都要编辑**:根目录 `.mod` 和文件夹内 `descriptor.mod` 都写 `replace_path = "xxx"` 才生效。
- 用 `replace_path` 覆盖整个文件夹时,**必须自带 generic 文件**:如 `common/national_focus/`、`common/unit_leader/` 等,否则数据库缺条目崩溃。
- `history/states/` **没有 generic 文件**,必须手写一个(原版没有"通用州")。
- 二分搜索时可以分批移除 `replace_path`(除 `history/states/` 和 `map/strategicregions` 外)。

## 5. 环境与启动器问题(Environment & Launcher)

| 症状 | 原因 / 修复 |
|---|---|
| error.log 大量奇怪错误,游戏异常 | **用户目录含非 ASCII 字符**(如 "Документы")——游戏不理解 UTF-8。把用户目录(或 Documents 重定向)改名为纯 ASCII,如 "Documents" |
| "the system cannot find the path specified" | 备份 mod → 退订所有 mod → 删 `Documents/paradox/Hearts of Iron IV/mod/` → 删 `mods_registry.json` 和 `launcher-v2.sqlite` → 把 hoi4.exe 加入杀毒软件白名单(尤其 Windows Defender 勒索软件防护的"允许的应用")→ 重新订阅测试 |
| 修改不生效 | Steam → 右键游戏 → 属性 → 本地文件 → "验证游戏文件完整性" |

## 6. 排查流程总纲(Flowchart)

```
收到报错/功能异常
├─ 先读 常见报错解读.md 的决策树(三种失败模式分类)
├─ 闪退 → setup.log / -crash_data_log 的 LastRead → 本文件第 3 节对照表
├─ error.log 有条目 → [xxx.cpp] 前缀定类型 → 本文件第 2 节查原文 → 修复 → 清空 error.log 重测
└─ 日志干净但不生效 → 静默失败清单(常见报错解读.md 第 3 节)+ 02 格式陷阱
```

**通用铁律**(与 常见报错解读.md 一致):
1. 报错里的文件路径和行号指向**你的文件**,先去那里看
2. 修完**清空 error.log 再测**,否则新旧报错混在一起
3. 所有 `common/` 文件夹内的报错都应修复,不能跳过
4. 排查崩溃用 `-crash_data_log`,平时不要开(拖慢游戏)
