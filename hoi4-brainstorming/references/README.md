## 版本锚定

资料基于 HOI4 **1.17.x**,部分教程标注至 1.14~1.16。
涉及版本差异的语法请以 `02-代码查询字典/提词器/documentation/`(游戏自带文档导出)为准。
2026-08 网上补充资料(wiki/贴吧/B站)抓取于 1.17.x,各文件头部标注来源 URL 与抓取日期。
