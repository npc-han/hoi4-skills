# 启动与验证操作卡（执行期速查）

> 供 hoi4-executing-plans 每单元验证使用。完整报错字典见 **hoi4-debugging**；最终验证见 **hoi4-verification-before-completion**。

## 日志位置

| 日志 | 位置 | 用途 |
|---|---|---|
| error.log | `Documents/Paradox Interactive/Hearts of Iron IV/error.log` | 主报错日志（需 `-debug` 才完整） |
| crashes/ | 同上 | 崩溃信息（meta.yml 的 LastRead） |
| logs/text.log | 同上 | 本地化冲突 |
| logs/game.log | 同上 | 控制台文档 |

## 启动参数（Steam 启动选项加）

- **`-debug`**：error.log 记录完整报错。**开发期间必须用**，不开部分报错不记录
- `-crash_data_log`：崩溃时记录 LastRead。**显著拖慢游戏，仅崩溃调试用**，平时不带

## 验证标准流程（每验证单元）

1. **写码期**：CWTools 校验当前文件（期望 0 错误）
2. **攒批验证门**（几组文件写完后）：
   - `-debug` 启动游戏 → 进主菜单 → 退出
   - **先清空 error.log** → 重读（期望无本 mod 条目）
   - 有报错 → 对照 hoi4-debugging 字典，明确原因才修
3. **游戏内确认**：目标内容可见可点击（国策可见 / 事件可触发 / 决议可用）——纯文本改动可跳过启动验证，但内容可见性验证不能省

## 热重载限定

- `common/` 内容基本需**重启游戏**才能加载
- 热重载仅限本地化/界面类（`reload localisation` 等 console 命令）
- 不要假设"改完不用重启"——加载类验证 = `-debug` 进主菜单即退

## 编码即时检查（写文件时）

- `.yml` → UTF-8 **带** BOM + 首行 `l_simp_chinese:`
- `.txt` / `descriptor.mod` → UTF-8 **无** BOM
- `.mod`（根目录）→ 带 BOM
